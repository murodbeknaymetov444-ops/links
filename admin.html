Nashr qilish

Nashr qilish: tugmani bosing → GitHub sahifasi ochiladi → o'sha yerda «Commit changes» ni bosing. ~1 daqiqadan keyin sayt yangilanadi. (Token shart emas; GitHub'ga kirgan bo'lishingiz kerak.)

GitHub'ga ulash (avtomatik nashr)

Token faqat shu brauzerda saqlanadi, repoga tushmaydi. GitHub → Settings → Developer settings → Fine-grained tokens → shu repo uchun Contents: Read and write ruxsati bilan yarating.
